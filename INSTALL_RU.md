# Установка и проверка «Музыкальной открытки» — оформление «Почта»

**Версия:** 17 октября 2026 г.
**Папка проекта на виртуалке:** `C:\Users\vboxuser\Desktop\musical-card`.
**Адрес для проверки:** `http://localhost:8001` — сайт открывается только на этом же компьютере.

Публикация через Caddy и статический IP — **следующий этап**, конфигурации для него в этот архив не входят. До него сайт не открывать в интернет.

## Что изменилось в этой версии

- **Новое оформление всех экранов:**
  - главная,
  - шаблоны (с фильтром по поводу),
  - редактор,
  - предпросмотр,
  - публикация,
  - открытка получателя,
  - страница ожидания,
  - страница ошибки.
- **Светлая и тёмная тема.** По умолчанию — как в системе. Переключатель есть на каждой странице, выбор запоминается в браузере.
- **Телефон:**
  - инструменты открываются из «пенала» внизу экрана;
  - библиотека и свойства объекта выдвигаются листами снизу, у каждого листа есть кнопка «Свернуть» или «Готово»;
  - редкие действия собраны в меню «⋯».
- **Сургучная печать.** У получателя кнопка Play — печать. Нажатие снимает размытие и запускает голос и музыку. Есть пауза, «Продолжить» и «Заново».
- **Кассета.** Звуковая панель редактора — кассета: катушки крутятся, пока звучит открытка. У голоса и музыки отдельная громкость.
- **«Музыка тише, пока звучит голос».** Это новая настройка открытки: пока звучит голос, музыка играет на 45 % от выбранной громкости. По умолчанию выключена, у старых открыток тоже.
- **Новые шрифты текста:** «От руки» (Caveat), «Округлый» (Nunito), «Каллиграфия» (Pacifico). Шрифты лежат в папке `fonts/` вместе с текстами лицензий SIL OFL 1.1. Сайт не обращается к внешним CDN.
- **Запись голоса** — в окне с большой кнопкой и таймером. Если закрыть окно во время записи, запись отменяется и микрофон отключается.
- **Ожидание.** На странице ожидания идёт обратный отсчёт до открытия.
- **Понятные ошибки.** Вместо сырого JSON сервера показываются понятные сообщения.

**Защита не ослаблена:**
- CSP, заголовки безопасности, лимиты, проверка токенов и медиа остались прежними.
- Сервер по-прежнему строго проверяет данные. Новые поля (`duckMusic` — только `true` или `false`, шрифты — только из списка) проверяются так же строго.
- Отдельные тесты закрепляют, что CSP не изменился и внешних ресурсов на страницах нет.

## 1. Резервная копия перед заменой

1. Остановите работающий Uvicorn (`Ctrl+C`).
2. Закройте редактор в браузере и дождитесь последнего сохранения.
3. Сделайте **полную** копию папки `musical-card` на отдельный диск. Обязательно включите в неё `backend\data\`, `db\` и `.venv\`.

```powershell
$source = 'C:\Users\vboxuser\Desktop\musical-card'
$backup = 'C:\Users\vboxuser\Desktop\musical-card-BACKUP-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
Copy-Item -LiteralPath $source -Destination $backup -Recurse
Write-Host "Сохранено: $backup"
```

Не копируйте и не восстанавливайте данные, пока работает сервер. Резервные копии содержат личные фото и голос — храните их конфиденциально.

## 2. Замена кода

Распакуйте **содержимое** ZIP в `C:\Users\vboxuser\Desktop\musical-card` с заменой одноимённых файлов.

**Не удаляйте** папки `.venv` и `backend\data`. Архив специально не содержит ни окружения, ни пользовательских данных.

Новые файлы и папки:
- `fonts/` — шрифты и их лицензии;
- `src/icons.js`, `src/theme.js`, `src/themeToggle.js`;
- `start-local.ps1`, `run-tests.ps1`;
- `tests/design-contract.mjs`, `tests/e2e_browser.py`;
- `backend/tests/test_design_assets.py`.

**Совместимость:**
- Старые черновики и опубликованные открытки открываются без изменений.
- Поле `duckMusic` для них считается выключенным.
- Обновлять зависимости не нужно: список в `requirements.txt` прежний.

```powershell
powershell -ExecutionPolicy Bypass -File .\run-tests.ps1
```

| Набор | Сколько | Что проверяет |
|---|---|---|
| `backend/tests` | **45** (было 31, добавлено 14) | API, защита, квоты; новое — шрифты и их лицензии, неизменный CSP, отсутствие внешних ресурсов и инлайн-скриптов, обход каталога в `/fonts`, строгие `duckMusic` и шрифты |

| `tests/*.mjs` (нужен Node.js) | 3 набора, **135** проверок | контракт браузер ↔ сервер, шаблоны; новое — цвета, контраст подписей (WCAG), иконки, шрифты, приглушение музыки, тема, тексты ошибок |

Все наборы должны закончиться `OK`. Если Node.js не установлен, скрипт пропустит третий набор — на работу сайта это не влияет.

**Сквозная проверка в настоящем браузере** — необязательная, около 3 минут. Она запускает отдельный сервер с временной папкой данных, поэтому ваши `backend\data` не затрагиваются. Затем проходит все сценарии как пользователь — на компьютере и на телефоне, в светлой и тёмной теме, включая запись с «виртуального» микрофона.

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
.\.venv\Scripts\python.exe -m playwright install chromium
powershell -ExecutionPolicy Bypass -File .\run-tests.ps1 -Browser
```

## 5. Запуск на локальном хосте

```powershell
powershell -ExecutionPolicy Bypass -File .\start-local.ps1
```

Откройте **на этой же виртуалке** `http://localhost:8001` и нажмите `Ctrl+Shift+R`, чтобы браузер забыл старые стили.

Сервер слушает только `127.0.0.1`, поэтому из домашней сети и интернета сайт недоступен. На `localhost` браузер разрешает запись с микрофона без HTTPS.

### Проверить вручную

**На компьютере:**
- **Главная.** Нажмите на печать в примере — размытие исчезает. Переключите тему; после перезагрузки страницы тема сохраняется.
- **Шаблоны.** Фильтр по поводу. Создание открытки из шаблона и с «чистого листа» каждого формата.
- **Редактор, оформление:**
  - текст и шрифты «От руки», «Округлый», «Каллиграфия»;
  - фигуры, стикеры, фоны каталога, своё фото и GIF;
  - рисунок;
  - слои, перетаскивание, поворот, размер;
  - отмена и повтор, смена формата.
- **Редактор, звук:**
  - запись голоса и загрузка файла;
  - музыка из подборки и своя;
  - две громкости и галочка «Музыка тише, пока звучит голос»;
  - кнопка воспроизведения на кассете.
- **Ссылка редактирования.** Откройте её в другом браузере — черновик на месте.
- **Предпросмотр.** Печать снимает размытие и запускает голос с музыкой. Проверьте «Пауза», «Продолжить», «Заново».
- **Публикация «Сразу».** Ссылка открывается; под открыткой есть «Авторы и лицензии использованных материалов».
- **Публикация «В назначенный час».** Видны только конверт и обратный отсчёт.
- **Удаление.** После удаления ссылки показывают «Письмо не дошло».

**На телефоне** (в Chrome: F12 → значок телефона, или настоящий телефон в домашней сети):
- нет горизонтальной прокрутки;
- «пенал» внизу, выдвижные листы;
- кнопки «Свернуть» и «Готово»;
- меню «⋯»: тема, ссылка, удаление;
- касанием перемещается объект;
- печать у получателя.

## 6. Откат при ошибке

1. Остановите Uvicorn.
2. Переименуйте неработающую папку.
3. Восстановите всю копию из шага 1.

**Не смешивайте старые и новые части** проекта. Если в новой версии уже созданы важные открытки, не удаляйте её данные до отката: `backend\data` совместим в обе стороны, у старой версии лишнее поле `duckMusic` просто не используется.

## 7. Следующий этап: Caddy и статический IP

Будет отдельный пакет с проверенными конфигурациями. Основа остаётся прежней:
- Uvicorn только на `127.0.0.1:8001`, один worker, `--proxy-headers --forwarded-allow-ips 127.0.0.1`;
- Caddy на 80/443, журнал доступа выключен (в адресах секретные токены);
- в `TRUSTED_HOSTS` — ваш домен или IP;
- наружу открыты только 80/443.

См. `DEPLOYMENT_CHECKLIST_RU.md`, `SECURITY_AUDIT_RU.md` и `LICENSES.md`.
