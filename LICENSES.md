## Политика добавления ресурсов

1. Проверять **исходного правообладателя и точную редакцию лицензии** для каждого ресурса. «Бесплатно» не значит «открытая лицензия».
2. Допускаются коммерческое использование и переработка; допустимы MIT, Apache-2.0, BSD, CC0, CC BY 4.0 и OFL 1.1 при исполнении их условий. Не считать их условия взаимозаменяемыми.
3. Для CC BY 4.0 указывать автора, название, источник, ссылку на лицензию и характер изменений. Официальный текст: https://creativecommons.org/licenses/by/4.0/
4. Для внешней музыкальной фонограммы проверять **и права на композицию, и права на запись**.
5. Для каждой будущей внешней зависимости документировать: имя, версию, URL исходного репозитория, URL текста лицензии, SPDX-идентификатор, NOTICE/attribution, дату проверки.
6. Не подключать материалы с `NC` (запрет коммерческого использования), `ND` (запрет производных произведений) или с неясным статусом.

Существующий комплект не требует публичной атрибуции сторонних авторов, поскольку **не содержит сторонних распространяемых материалов**. Это не является автоматической проверкой материалов, которые пользователь загрузит позже.
