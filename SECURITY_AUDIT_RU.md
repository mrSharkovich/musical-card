# Musical Card — технический аудит и итоговая исправленная сборка

**Дата:** 16 октября 2026. **Исходная база:** предыдущая объединённая сборка с 16 тестами.

## Исправлено в этой версии

1. **Чужие файлы:** новые проекты не могут присоединять загруженные файлы; при сохранении проверяется владелец каждого media ID; публикация сохраняет идентификатор владельца и повторно проверяет ссылки; публичная выдача проверяет владельца. Старые черновые файлы без owner разрешены **только** проектам, которые уже ссылались на них до обновления. Старые публичные публикации без owner **не получают доступ** к файлам до перепубликации их владельцем.
2. **Секреты в URL:** изображения/аудио черновика выдаются только с `X-Edit-Token`, который фронтенд отправляет с `fetch`; браузер отображает полученные файлы из `blob:`. Сохранённые URL удаляются от прежнего параметра `?edit_token=`. Заголовок не попадёт в обычный access log URL, но редакторский токен всё ещё передаётся в **пути API** `/api/projects/{token}`: не включайте access logs на сервере/прокси и не раскрывайте секретные ссылки.
3. **Загрузка изображений:** кроме сигнатур Pillow проверяет возможность декодирования, форматы, число пикселей, общее число пикселей анимации и число кадров. SVG не допускается. Для аудио выполнены дополнительные проверки некоторых контейнеров, **но это не равно полной независимой проверке всех аудиокодеков**.
4. **Лимиты DoS:** маршруты классифицируются по ASGI `scope.path`, а не через конструируемый с Host URL; установлен TrustedHostMiddleware; лимитер не создаёт бесконечные записи на каждую уникальную комбинацию пути; общий и целевой предел на IP. Важно: лимитер работает **в памяти одного процесса** и не защищает от распределённой атаки.
5. **Данные:** список полей элементов и аудио проверяется по разрешённым наборам, повторные ID, числовые NaN/бесконечности, цвета, источники, точки рисунка отклоняются. Проекты и метаданные имеют ограничения байт, числа файлов/открыток, объёма пользовательского медиа.
6. **Удаление и хранение:** появился DELETE по секретному токену редактирования (редактор использует его из кнопки «Удалить»), удаляются связанные новые публичные ссылки и принадлежащие проекту вложения; плановая очистка никогда не удаляет отложенную открытку до её открытия и завершения срока хранения. Legacy cards без editOwner нельзя автоматически связывать с владельцем.
7. **Лицензии:** реестр `LICENSES.md` фактически перечисляет встроенную музыку/фоны/стикеры; показываются подписи для CC BY / CC BY-SA при просмотре открытки. Два фона с неустановленным автором и один ранее неподтверждённый ресурс убраны из файлов поставки. Исходный MIT `LICENSE` и авторское уведомление сохранены.
8. **Зависимости:** файлы requirements обновлены на линейки FastAPI/Starlette, Uvicorn, python-multipart с исправлениями известных уязвимостей. Добавлен Pillow. Перед внешним доступом повторить `pip check` и проверить CVE установленной версии.

- `PYTHONPATH=backend python -m unittest discover -s backend/tests -v` — **28/28 OK**.
- `python -m unittest discover -s db/tests -v` — **16/16 OK**.

**Важно:** тестовая среда имела FastAPI **0.128.2 / Starlette 0.50.0**, Pillow **12.3.0**, httpx **0.28.1**; финально указанные в `requirements.txt` новые FastAPI/Starlette/Uvicorn/python-multipart **нельзя было скачать из этой тестовой среды из-за отсутствия доступа к PyPI**. Поэтому полную совместимость именно закреплённого комплекта необходимо подтвердить установкой и тестами на Windows 11. Это не «аудит безусловно завершён».

## Остающиеся внешние риски и ограничения

- **Не проведены:** проникновение по WAN, браузерные тесты микрофона и анимаций, нагрузочный/распределённый стресс-тест, верификация Windows Firewall, Caddy/TLS, NAT/router/VirtualBox, тест резервного восстановления и полная правовая экспертиза лицензий.
- **Аудиофайлы:** сервер не перекодирует их в изолированной песочнице. Браузер остаётся декодером; для публичного высоконагруженного хостинга желателен отдельный обработчик с изоляцией и тайм-аутами.
- **Один worker:** файловый storage и rate limit не масштабируются горизонтально. Для более серьёзного публичного хостинга надо мигрировать на БД + объектное хранилище, централизованный лимитер и отдельные квоты по пользователям.
- **Нет регистрации:** любой обладатель редакторского токена может полностью менять или удалить проект. Восстановить утерянный токен без учётной записи нельзя.
- **Ресурсы:** ограничение RAM для одноразового запроса остаётся заметным (аудио до 15 МБ); нужны инфраструктурные ограничения и мониторинг.
- **Данные и лицензии:** у администратора должен быть процесс обработки жалоб, удаления незаконных материалов и приватных данных, а также опубликованная политика сроков хранения и защищённое хранение бэкапов. Нельзя гарантирoвать, что загруженный пользователем материал имеет подходящую лицензию.

**Итог:** эту сборку можно **установить для локального тестирования**. Публичная публикация — **только после тестов на Windows 11 и проверки инфраструктуры**, не ранее.

## Изменения 17 октября 2026 г. — оформление «Почта»

Оформление переделано **без ослабления защиты**.

**Политика CSP:**
- Не изменилась: `default-src 'self'`, `script-src 'self'` без `unsafe-inline` и `unsafe-eval`.
- Тест `test_csp_is_unchanged_on_pages_and_api` сравнивает её дословно.

**Шрифты:**
- Отдаются с того же origin из `/fonts` через `StaticFiles`.
- Тип `font/woff2` и заголовок `nosniff` задаются явно.
- Попытки выйти за пределы каталога (`/fonts/../…`, в том числе закодированные) не проходят — это проверяет тест.

**Внешние ресурсы и скрипты:**
- Внешних CDN, `@import`, инлайн-скриптов, инлайн-обработчиков `on…=""`, `eval` и `javascript:` в коде нет — это закреплено тестами.
- Попутно убран инлайн-обработчик `onclick` из окна копирования ссылки. Он и раньше не работал из-за CSP.
- Ранний скрипт темы `src/theme.js` подключён как отдельный файл того же origin и не использует внешние данные.

**Новые поля проекта проверяются строго:**
- `duckMusic` — только `true` или `false`; строки и числа отклоняются.
- Шрифт текста — только из списка `TEXT_FONTS`. Попытка CSS-инъекции через имя шрифта отклоняется сервером, а в браузере неизвестное значение заменяется на `serif`.

**Цвета из каталога в разметке:**
- Попадают в `style` только в виде `#RRGGBB` (`safeColor`).
- Названия шаблонов и символы украшений экранируются (`esc`).

**Запись голоса:**
- Закрытие окна во время записи отменяет её и освобождает микрофон.
- При переходе на другую страницу открытые окна закрываются.

**Страница ожидания:**
- Обратный отсчёт не обращается к серверу циклически: автоматическая проверка выполняется один раз, при переходе через ноль.

**Ограничение частоты запросов:**
- Лимитер не менялся: 120 запросов в минуту на IP.
- Сквозной браузерный тест учитывает его и делает паузы.
