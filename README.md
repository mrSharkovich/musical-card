# Музыкальная открытка — Musical Card

Веб-приложение без регистрации: редактор открытки, текст, рисунки, изображения, GIF, стикеры/фоны, голос и музыка с двумя регуляторами громкости, готовые шаблоны, публикация сразу или по времени. Сервер FastAPI + файловое хранилище JSON и медиа; браузерный UI на HTML/CSS/vanilla JavaScript.

## Актуальный запуск на Windows 11 (VirtualBox)

См. **[`INSTALL_RU.md`](INSTALL_RU.md)** — резервное копирование, безопасная замена файлов, установка зависимостей, 44 автоматических теста, проверка в браузере и порядок отката.

```powershell
cd ".\musical-card"
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-dev.txt
$env:TRUSTED_HOSTS="localhost,127.0.0.1,192.168.1.102"
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8001 --workers 1 --no-access-log --no-proxy-headers
```

Локально: `http://192.168.1.102:8001`. **Не публиковать этот HTTP-порт в WAN.** При внешнем доступе использовать HTTPS reverse proxy, Uvicorn bind `127.0.0.1`, ограничения прокси и Firewall.

## Маршруты браузера

- `#/` — главная;
- `#/templates` — каталог оформлений;
- `#/edit/:editToken` — секретная ссылка редактора (пароль);
- `#/preview/:editToken` — предпросмотр;
- `#/publish/:editToken` — публикация;
- `#/card/:publicId` — публичный просмотр либо ожидание назначенного времени.

Без учётных записей: потерянный редакторский токен невозможно восстановить; владелец токена может удалить проект. Черновые медиа отдаются браузеру только с `X-Edit-Token`, а не с токеном в query-параметре URL.

## API и хранение

`POST /api/projects`, `GET/PUT/DELETE /api/projects/{token}`, `POST /api/assets` (multipart `file` + `edit_token`), `GET /api/media/draft/{asset_id}` (header `X-Edit-Token`), `POST /api/projects/{token}/publish`, `GET /api/cards/{id}`, `GET /api/media/cards/{id}/{asset_id}`, `GET /api/catalog/...`.

Изображения и звук проходят серверные проверки размера/формата и принадлежности проекту. Публикация делает независимый снимок содержимого. Запланированная открытка скрывает проект и медиа до даты. `backend/data/` содержит пользовательские данные и **никогда не должен публиковаться** или перезаписываться из архивов программы.
