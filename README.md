# Музыкальная открытка — фронтенд без внешних библиотек

## Запуск

Для локального тестирования в директории проекта:

```bash
python -m http.server 8000
```

Открыть http://localhost:8000/ . Не открывать `index.html` напрямую по протоколу file:// — ES-модули и микрофон могут не работать.

## Маршруты

- `#/` — главная
- `#/templates` — шаблоны
- `#/edit/:editToken` — редактор
- `#/preview/:editToken` — предпросмотр
- `#/publish/:editToken` — публикация
- `#/card/:publicId` — получатель или экран ожидания

Используется hash-routing, поэтому Python-сервер может отдавать статический index.html без SPA fallback.

## Подключение Python-бэкенда

Изменить `API_BASE` в `src/config.js`. Сервер должен реализовать JSON API:

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | `/api/projects` | `{ "project": CardProject }` | `{ "editToken": "..." }` |
| GET | `/api/projects/{editToken}` | — | `{ "project": CardProject }` |
| PUT | `/api/projects/{editToken}` | `{ "project": CardProject }` | `{ "ok": true }` |
| POST | `/api/assets` | multipart `file` | `{ "url": "/media/..." }` |
| POST | `/api/projects/{editToken}/publish` | `{ "opensAt": "2026-10-14T09:00:00.000Z" \| null }` | `{ "publicId": "..." }` |
| GET | `/api/cards/{publicId}` | — | `{ "status": "scheduled", "opensAt": "..." }` ИЛИ `{ "status": "ready", "project": CardProject }` |

Для публикации сервер должен делать неизменяемый снимок открытки. Изменения черновика не должны менять опубликованную карточку, если нет явной операции обновления.

**Важно:** часовой пояс задаётся при публикации датой из локального поля, конвертируемой в UTC ISO 8601. Бэкенд должен сравнивать UTC-время с серверным временем, никогда не отдавать содержимое открытки до открытия, а также защищать медиа недоступной открытки (в том числе от просмотра по прямым адресам). Редакторский токен должен генерироваться криптографически надёжно и рассматриваться как пароль; URL редактирования нельзя раскрывать получателю.

Доработки бэкенда: валидация загрузок, лимиты, CORS/CSRF по архитектуре, ограничения частоты запросов, очистка старых открыток, политика хранения данных, антивирусная проверка файлов, блокировка MIME-spoofing, безопасность SVG и раздачи медиа.

## Демо-режим

`API_BASE = ''` использует localStorage для JSON открыток и IndexedDB для медиа. Демо-ссылки **работают только в браузере, где создан проект**, и **не обеспечивают серверную защиту от раннего доступа**. Нельзя использовать демо для настоящей рассылки. Для межустройственного использования и реального отложенного доступа нужен Python API.

## Ограничения текущего фронтенда

- Рисование мышью и одним пальцем, базовое перемещение/изменение размеров/поворот объектов.
- GIF анимируется при поддержке браузера; инструменты обрезки/фильтров изображений в данном варианте не реализованы.
- Библиотека музыки состоит из трёх оригинальных синтезируемых мелодий; музыка из внешних каталогов не загружается.
- Реализованы основные страницы, сохранение, импорт файлов, запись голоса, две громкости, публикация и размытие перед Play.
- Для продакшена нужны автотесты, профессиональная обработка жестов (pinch/zoom), полноценные операции с графикой, проверка доступности и кроссбраузерное тестирование.
