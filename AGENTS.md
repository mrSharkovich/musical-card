# Инструкции для Codex

## О проекте

Это командный проект для хакатона, над которым работают три человека.

Моя задача — разработать бэкенд для уже существующего фронтенда.

На данный момент пока еще не реализована база данных для хранения. Позже мы её подключим. Учти это.

Все объяснения, планы, комментарии и ответы предоставляй на русском языке.

## Контекст проекта

Перед началом работы обязательно:

1. Изучи файл `docs/task.txt` с описанием приложения.
2. Изучи изображение `docs/task.jpg` с заданием хакатона.
3. Если не можешь прочитать изображение, сообщи об этом.
4. Проанализируй структуру существующего фронтенда.
5. Определи, какие функции бэкенда необходимы для работы приложения.

Не придумывай требования, которых нет в задании или описании проекта. Если информации недостаточно, задай уточняющие вопросы.

## Правила разработки

- Разрабатывай бэкенд в отдельной папке `backend`.
- Не изменяй существующий фронтенд без моего разрешения.
- Используй простые, надёжные решения, подходящие для хакатона.
- Используй решения с открытой лицензией или для которых не нужна лицензия.
- Используй такие решения, чтобы не было проблем с лицензией.
- Отдавай приоритет минимально рабочей версии приложения (MVP).
- Не добавляй ненужные библиотеки и сложную архитектуру.
- Учитывай совместимость API с существующим фронтендом.
- Не записывай секретные ключи и пароли непосредственно в код.

## Порядок работы

1. Перед реализацией новой функциональности объясни план.
2. Дождись моего подтверждения перед существенными изменениями.
3. Создавай код небольшими логическими частями.
4. После каждого этапа проверяй работоспособность.
5. Если возникают ошибки, объясняй их причины и предложи способы исправления.
6. Если после 3 итераций не выходит исправить ошибку, остановись и сообщи мне.
7. После завершения этапа перечисляй созданные и изменённые файлы.

## Работа с Git

- Мы работаем в команде, поэтому учитывай изменения других участников.
- Не переключай Git-ветки без моего разрешения.
- Не выполняй `git commit`, `git push`, `git merge` и `git reset` без моего разрешения.
- Не удаляй и не перезаписывай чужие изменения.
- Перед потенциально опасными действиями обязательно спрашивай разрешение.

## Общение

- Всегда общайся со мной на русском языке.
- Объясняй технические решения простым и понятным языком.
- Если предлагаешь несколько вариантов, рекомендуй наиболее подходящий для хакатона.
- При необходимости показывай команды для терминала VS Code.
- Не приступай к реализации больших задач без предварительного согласования.
